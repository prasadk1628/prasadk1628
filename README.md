**Python · Pandas · Streamlit · Geospatial Analysis**

**Key findings:**

* Overall complaint resolution rate: **61%**
* Identified underperforming agencies and wards
* **October–November** identified as a high-risk period for infrastructure complaints

Built an interactive Streamlit dashboard with filtering, KPI monitoring, and geospatial visualization.
